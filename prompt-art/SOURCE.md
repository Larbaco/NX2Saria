# Button prompt art

Source: JulioCacko, FREE Input Prompts Pack 1.4 (CC0 1.0)

The 128x128 pictures in this folder are the ones `tools/pad_prompts.py` draws the Xbox, PlayStation, Steam Deck and
keyboard and mouse button prompts from (`tools/prompt_art.py` names them). They are copied unmodified from the pack
below. `SHA256SUMS` lists every one, and `tools/check_content.py` refuses a picture in this folder that is not in that
list or differs from it.

Which files: the pictures of `XGamepad/Default`, `XGamepad/Light`, `P5Gamepad/Default`, `P5Gamepad/Light`,
`Keyboard_Mouse/Blanks` that `tools/prompt_art.py` `art_files` names, and every picture of `Keyboard_Mouse/Dark` and
`Keyboard_Mouse/White` (281 files, `Source/<set>/<style>/<name>.png` in the zip). Each one is byte-for-byte the same
file in `Source.zip`, checked by SHA-256 on 18 November 2026. The same 281 pictures, with the same SHA-256, are the
button art of the earlier NX2navi releases (`prompt-art/` of `NX2navi-app-0.11.0-rc4.zip`).

The button symbols show the labels of Xbox and PlayStation controllers so that players can tell which button to press.
