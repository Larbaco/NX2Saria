- Field of view now works on game 1.1.1 (Display tab), and the mouse can click the pause menu's tabs.
- The Controls tab says what each button does in the game, under each button's name.
- Above 60 fps: Epona clears fences, Gohma reaches the ceiling, frozen Zoras stop shaking, battle music ends.
- Fixes a crash a moment after a save loads; a start that fails for lack of memory now says why and what to do.
- Logs and bug reports no longer show your account name, your computer's name or your user folder.

Your saves, mods and settings stay where they are when you update.
Every file is built and uploaded by GitHub Actions; the install guide shows how to check it.
On some NVIDIA PCs the update can spend a long time on shaders; 0.19.1 will shorten it.
