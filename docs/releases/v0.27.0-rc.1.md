- Fixed: with FSR 4 frame generation (Windows, Radeon), the frame after a menu or another frame the game did not prepare restarts the generation instead of mixing two pictures.
- Fixed: on Linux with DLSS and DLSS frame generation together (GeForce RTX 40 and 50), the two no longer call NVIDIA's library at the same time.
- When the game crashes, the session report now says on which graphics card and with which settings. It holds nothing a normal report does not, and nothing is sent unless session reports are on.
- The game's log: the line that says why the game crashed is always written whole, and a crash with the log sent to a terminal no longer leaves the game hanging.
- This update rebuilds a small part of the game; the long step, the game's own code, is not repeated.

Your saves, mods and settings stay where they are when you update.
Pre-release: the first candidate of 0.27.0, for the Preview channel. The two graphics fixes were made from reading the code and the SDKs: the project has no computer where FSR 4 or DLSS frame generation runs. DLSS and DLAA on Windows were not yet played with this build.
