- New since rc.1: `foliage_distance` in `nx2saria.ini` (0.5 to 3, default 1) draws the grass, bushes and flowers of the fields nearer or farther. It takes effect after a restart, on game 1.1.1.
- A trigger (ZL, ZR) counts only after it has rested for one second, so a controller that connects with a trigger not at rest no longer holds the button down. The triggers do nothing in the first second after a controller connects.
- Linux: on a kernel older than 6.7 the game is much slower. The launcher now says so on its home screen and the game's log names the kernel.
- From rc.1: fixes for FSR 4 frame generation and for DLSS with DLSS frame generation on Linux, a crash report that says the graphics card and settings, and the game's crash line always written whole.
- This update rebuilds a small part of the game; the long step, the game's own code, is not repeated.

Your saves, mods and settings stay where they are when you update.
Pre-release: the second candidate of 0.27.0, for the Preview channel. The first candidate was installed, built, run, crashed on purpose and updated to by an automatic test on Linux. The two graphics fixes were made from reading the code; DLSS and DLAA on Windows were not yet played with this build.
