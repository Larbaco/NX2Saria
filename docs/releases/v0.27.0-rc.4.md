- Fixed since rc.3: on Linux, updating with the launcher's command line (`launcher.cli update`) changed the version and then stopped with an error before rebuilding the game. This came in with rc.2. Updating from the launcher's window was not affected.
- From rc.3, experimental and off by default: a settings tab in the game's own pause menu. `pause_settings_tab = 1` in `nx2saria.ini` turns it on (game 1.1.1); R on the *Menu* tab opens it.
- From rc.2: `foliage_distance` in `nx2saria.ini`, triggers that count after a second at rest, and the notice for Linux kernels older than 6.7.
- From rc.1: fixes for FSR 4 frame generation and for DLSS with DLSS frame generation on Linux, a crash report that says the graphics card and settings, and the game's crash line always written whole.
- This update rebuilds a small part of the game; the long step, the game's own code, is not repeated.

Your saves, mods and settings stay where they are when you update.
Pre-release: the fourth candidate of 0.27.0, for the Preview channel. The third candidate was installed, built, run, crashed on purpose and updated to through the launcher's window by an automatic test on Linux; that test found the command line fault. DLSS and DLAA on Windows, and the new tab with a real controller, were not yet played with this build.
