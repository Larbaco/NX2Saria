- New: `foliage_distance` in `nx2saria.ini` (0.5 to 3, default 1) draws the grass, bushes and flowers of the fields nearer or farther, on game 1.1.1.
- A trigger (ZL, ZR) counts only after one second at rest, so a controller that connects with a trigger not at rest no longer holds the button down.
- Fixed: FSR 4 frame generation (Windows, Radeon) no longer mixes two pictures after a menu, and on Linux DLSS and DLSS frame generation no longer call NVIDIA's library at the same time.
- A crash report now names the graphics card and the settings. On Linux the launcher warns about a kernel older than 6.7, where the game is much slower.
- Experimental, off by default: a settings tab in the game's own pause menu. `pause_settings_tab = 1` in `nx2saria.ini` turns it on (game 1.1.1).

Your saves, mods and settings stay where they are when you update. The update rebuilds a small part of the game, a minute or two.
The same game and launcher as 0.27.0-rc.4, played on Windows with a GeForce RTX 3050 6GB and on Linux with a Radeon RX 6700. The frame generation fixes come from reading the code: the project has no computer where they run.
