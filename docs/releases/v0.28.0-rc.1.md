- The button pictures follow a remapped controller: with A and B swapped on the Controls tab, the game shows the button you press.
- The mouse cursor hides after three seconds at rest over the game and comes back when it moves; `cursor_hide = 0` in `nx2saria.ini` keeps it shown.
- New in `nx2saria.ini`: `mouse_invert_x`, `mouse_invert_y` and `mouse_sens_y` for the mouse camera, and `background_mute = 1` to silence the game while another window has the focus.
- Experimental `pause_settings_tab = 1` (game 1.1.1): the tab now sits beside the pause menu's own tabs, takes clicks, and has Sound, Controls and Game rows and a way into the whole settings menu.
- The launcher offers the newest version even when GitHub lists an older one first.

Your saves, mods and settings stay where they are when you update. The update draws the button pictures again and rebuilds a small part of the game, a minute or two.
Pre-release: the first candidate of 0.28.0, for the Preview channel. None of it was played yet: the cursor, the mute, the mouse options and the pause menu's tab were tried in automatic runs without a window on Linux, and the Windows cursor code was only compiled.
