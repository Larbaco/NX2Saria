- Installing and updating no longer run the PC out of memory: each compile starts only when there is memory free for it.
- A PC with memory to spare now compiles on all its processors; the old "--jobs 4 on 16 GB" advice is gone.
- This update compiles the whole game once, which takes about as long as the compile step of a first install.
- The game itself is the same as in 0.18.2: nothing changes in play.

Your saves, mods and settings stay where they are when you update.
Pre-release: the new build has not yet installed the game on a Windows PC.
