- New: *Quit Game* in the game's own menus on game 1.1.1: a fourth entry on the title screen, and a third button in the question the pause menu's *Title Screen* opens. `quit_menu = 0` in `nx2saria.ini` turns it off.
- New: after the game crashes, the launcher offers to send the start and the end of the game's log. Nothing is sent unless you choose *Send the Log*, and *See What Is Sent* shows the exact text first. Settings, Session Reports, *Ask After a Crash* turns the offer off.
- Fixed: with NVIDIA's low latency on and frame generation off, the game no longer crashes inside the graphics driver after a few seconds on NVIDIA drivers from 2023 (546.31 and older).
- Linux, Radeon RX 6000 and newer with Mesa 26.2 or 26.3: the game no longer ends with "the GPU device was lost" within seconds; it draws through the mesh fallback there until Mesa's fix is released.
- Coming from 0.25.0, this update compiles part of the game again, a few minutes, because *Quit Game* changes three of the game's functions.

Your saves, mods and settings stay where they are when you update.
The same code as 0.26.0-rc.2, played on Windows with a GeForce RTX 3050 6GB on driver 546.18 and on Linux with a Radeon RX 6700. *Quit Game* from the pause menu was used on Linux, not on Windows.
