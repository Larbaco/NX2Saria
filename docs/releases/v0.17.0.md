- Item trackers can now follow your progress live: collectibles, chests and quests as you complete them.
- The first is hyrule-tracker, once its NX2Saria support is released (its pull request is open).
- Trackers can also read which way Link faces, and find this game's save folder by themselves.
- It uses the tracker setting of 0.16.0: `tracker_api = 1` under `[tracker]` in `nx2saria.ini`. It is off by default.

Your saves, mods and settings stay where they are when you update.
With the tracker setting off, the game runs as in 0.16.0.
