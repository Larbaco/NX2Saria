- The Cheats tab is back in the game's menu when a mod you enabled brings cheats: switch each one on or off there, and it takes effect with Apply.
- The log counts what each cheat did: how many times it wrote to the game's memory and how many writes were refused.
- New: session reports. After you play, the launcher can send a short summary of how the game ran (versions, hardware, graphics options, frame rate, how the session ended) to the project's own server, to find bugs and see what needs optimizing.
- The launcher asks about them once after an update, the next time you open it. Reports turn on if you choose Send, close the question, or give no input for 30 seconds; Don't Send keeps them off, and Settings > Session Reports changes it at any time.
- A report carries no name, account, folder, save, country or installation id, and your IP address is not kept; See What Is Sent shows the exact text.
- Send a Comment in the launcher sends the project a note you write.

Your saves, mods and settings stay where they are when you update.
The same code as 0.24.0-rc.1, played on a Windows laptop with NVIDIA before this release. The Cheats tab was tried with the menu's test hook, not yet with a controller or a mouse.
