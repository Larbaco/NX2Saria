- Fewer stutters in busy towns such as the Market: turning around no longer makes the game restart loading the next area each time.
- On screens wider than 16:9 the camera stays close in crawlspaces and tight passages, as it does at 16:9.
- `changebank_hold = 0` and `camera_clearance_fix = 0` in `nx2saria.ini` turn the two changes off, and the log counts what each one did.
- On NVIDIA under Windows, this is the first update that finds the shaders already prepared, so it takes seconds.
- For testers: `NX2SARIA_REPLAY_PHASES=1` times each step of the game's drawing work, to find where the CPU time goes.

Your saves, mods and settings stay where they are when you update.
The same code as 0.22.0-rc.1, played on Linux and on a Windows laptop with NVIDIA before this release.
