- Map trackers such as Ocarina Atlas 2.3.0 and later can follow your game live: where Link is and what you collected.
- To use one, set `tracker_api = 1` under `[tracker]` in `nx2saria.ini` and start the game again. It is off by default.
- The tracker can only read the game's memory, never change it, and only programs on this PC can reach it.
- With it off, the game runs as in 0.15.0.

Your saves, mods and settings stay where they are when you update.
Superseded by 0.17.0, which has all of 0.16.0: update to it instead.
