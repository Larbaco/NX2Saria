- The mouse can click the pause menu's tabs, and the wheel over the tab row turns the page.
- Field of view on game 1.1.1 now widens the view in play (Display tab); in 0.18.7 it did nothing.
- A model that does not fit in its memory no longer crashes the game a moment after a save loads.
- Logs, F8 bug captures and crash reports no longer show your account name, your computer's name or your user folder.
- Every file of this release is built and uploaded by GitHub Actions, with a signed record you can check.

Your saves, mods and settings stay where they are when you update.
Pre-release: a release candidate for the Preview channel. Not tried on Windows yet: tab clicks and field of view.
