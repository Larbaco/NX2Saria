# NX2Saria 0.21.2-rc.2 in detail

The log lines and tests behind the [0.21.2-rc.2 release notes](../releases/v0.21.2-rc.2.md). How to install or update
is in [the install guide](../install.md). It is the second release candidate of 0.21.2, for launchers on the Preview
channel, and has everything of [0.21.2-rc.1](v0.21.2-rc.1.md) plus the changes below.

## NVIDIA's shader cache in the game's folder (#63)

On an NVIDIA laptop, each of four updates in one day found the driver's shader cache mostly gone (3 or 4 of 12
sampled libraries) and built all 42,142 variants again, 15 to 30 minutes each time; the launcher's new lines showed
`%LOCALAPPDATA%\NVIDIA\GLCache` going from 1.62 GB in 2 files to 1.37 GB in 4 files across one preparation. On
Windows with NVIDIA's driver files present, the process now sets `__GL_SHADER_DISK_CACHE_PATH` to an `nvidia-cache`
folder beside the game, `__GL_SHADER_DISK_CACHE_SIZE` to 8 GiB and `__GL_SHADER_DISK_CACHE_SKIP_CLEANUP=1`, each only
when the environment does not set it already, before any driver loads: the game, its tools and the preset's probe
alike, whether started by the launcher, Steam or the exe. NVIDIA documents these variables for Linux only; whether
the Windows driver reads them is what the next update shows.

- Start: `vk: NVIDIA's shader disk cache: __GL_SHADER_DISK_CACHE_PATH=... (the game's, beside the exe), ...`, or
  `(the player's, from the environment)`.
- Before the sample: `vk_pipeline: library warm: NVIDIA's shader disk cache folder ... holds N GB in M files`; the
  launcher's shaders step counts `nvidia-cache` first, before and after.
- `nvidia_cache_dir = 0` (or `NX2SARIA_NVIDIA_CACHE_DIR=0`) turns it off. Linux keeps its own folder as before.
- Test: `tests/nvidia_cache_check.py`.

## Mesh shaders on Intel (#64)

On Intel Arc (a B390 and a B580, Windows driver 101.9150), the fog showed holes with the native mesh pipelines, and
the shader changes of 0.18.2 did not remove them; only `mesh_fallback = 1` did. `mesh_fallback = auto`, the default,
now takes the fallback on every Intel card with mesh shaders, and the start line says why:
`vk: mesh fallback: ... (the default on Intel's drivers, where native mesh pipelines left holes in the fog on Arc
cards; mesh_fallback = 0 draws them natively)`. NVIDIA, AMD RDNA 3 and 4 and RADV stay native. Test:
`tests/mesh_path_check.py`.
