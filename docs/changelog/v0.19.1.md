# NX2Saria 0.19.1 in detail

The log lines and tests behind the [0.19.1 release notes](../releases/v0.19.1.md). How to install or update is in
[the install guide](../install.md). Fixes only, on top of [0.19.0](v0.19.0.md).

## Shader preparation in an update (#39)

On an NVIDIA laptop, the update to 0.19.0-rc.2 took 124.8 minutes: the graphics driver had dropped part of its shader
cache, so the preparation built all 42142 variants again, and three of them, very large compute shaders, took 1.5
hours between them. The game itself never creates those: its boot already leaves out compute shaders over 512K SPIR-V
words that no run has dispatched (`compute-used.bin`).

- The preparation (`--prepare-shaders`, `--warm-shaders`) now leaves them out by the same rule. On game 1.1.1 these
  are 20 shaders (15 of `agl_ndsr_vr_light.pck`, 2 of `agl_ndsr.pck`, 3 of `tera_develop.sharcb`, 0.9 to 2 million
  words each). Log: `prepare-shaders: N large compute shaders left out (never dispatched)`, and each one named.
- When every variant has been handed out and only builds that have been in the driver's hands for 5 minutes or more
  are left (`NX2SARIA_PREPARE_STALL_S`, 300; 0 waits for all), the preparation names them, writes in
  `shader-warm.txt` where the game goes on, and ends with success; the build log says `the rest continues in the
  game, in the background`, and the next start logs `going on with the warm an earlier run began`.
- The known issues say how to give the NVIDIA driver's shader cache more room (NVIDIA Control Panel, Manage 3D
  settings, Shader Cache Size: 10 GB or Unlimited), in every translation.

## The launcher's What's New (#35)

- The notes are shown whole in a scrolling area with a thin scroll bar: the mouse wheel over it, dragging the bar,
  PgUp/PgDn, or the right stick on a controller. Markdown links show as their text, and a line of links alone is left
  out. One line in `launcher.log` when the notes do not fit.
- `tools/release_files.py tag` refuses notes whose line of links is among their first six lines, which older launchers
  show as plain text.

## Bench test runs (#36)

- Values the settings menu's test hook sets (`NX2SARIA_MENU_TEST_SET`) are no longer written to `nx2saria.ini` at
  exit; only `SAVE=1` writes. Log: `cfg: menu test values not saved: N key(s)`. Nothing changes for players.

## Tested

- Bench (Linux): the preparation left the 20 out and built 42122 variants in 43 s; with a 2 s limit and a variant
  held for 600 s, it ended with code 0 in 37 s, and the next start finished the warm.
- The launcher's notes with the notes of 0.18.6 to 0.19.0-rc.2, before and after, under Xvfb.
- Windows builds of each change by the release workflow. Not seen on NVIDIA yet: the update's time with the driver's
  cache partly gone.
