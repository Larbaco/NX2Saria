# NX2Saria 0.22.0-rc.1 in detail

The log lines and tests behind the [0.22.0-rc.1 release notes](../releases/v0.22.0-rc.1.md). How to install or update
is in [the install guide](../install.md). It is the first release candidate of 0.22.0, for launchers on the Preview
channel, and has everything of [0.21.2](v0.21.2.md) plus the changes below.

## Holding the preloaded neighbour map (#61)

In a town such as the Market, the game preloads the neighbouring area the camera faces, and each turn of Link
cancelled that load and started another. The `changebank_hold` set keeps the game's choice for 2 s (`changebank_hold_ms`)
instead; a direct request, the same map, a vanished unit or a pause of more than 500 ms still let the game choose at
once. On the bench, two minutes of walking in the Market went from 80 changes to 6 loads, from 29 to 1 and from 17 to
1, and the loading threads' CPU time from 7.6 s to 2.4 s per 100 s; the frame rate did not change there, where the
frame is bound by the replay and the GPU, so the gain is expected on PCs with fewer cores. Details:
[changebank-hold.md](../changebank-hold.md).

- `patches:` shows `changebank_hold on|off`; a start line, up to 8 event lines, a line a minute when the choice
  changes and the session's totals.
- Test: `tests/changebank_hold_check.py`.

## Camera clearance at 16:9 on wider pictures (#62)

The camera's clearance check reads the picture's aspect ratio, so on 21:9 the sphere it keeps free was 1.26 times its
16:9 size (1.8 times on 32:9), and the camera stayed farther out in crawlspaces. The `camera_clearance` set gives that
calculation 16:9. On the bench at 21:9 it replaced 1998 of 1998 reads. `camera_clearance_fix = 0` turns it off.
`patches:` shows `camera_clearance on|off`, with a start line and the totals per site at the end. Test:
`tests/camera_clearance_check.py`. The second site (`0x71b624`) did not run on the bench.

## Replay timing for profiling (#65)

`NX2SARIA_REPLAY_PHASES=1` times each phase of the replay (binding, entries, draws, the mesh fallback, the uniform
snapshot) every 600 frames; it is off by default and logs nothing then. The study it served is in
[replay-cpu.md](../replay-cpu.md). `NX2SARIA_POS_TRACE` (#62) writes Link's position each tick for physics checks.
