# NX2Saria 0.21.1-rc.1 in detail

The log lines and tests behind the [0.21.1-rc.1 release notes](../releases/v0.21.1-rc.1.md). How to install or update
is in [the install guide](../install.md). It is the first release candidate of 0.21.1, for launchers on the Preview
channel, and has everything of [0.21.0](v0.21.0.md) plus the fixes below.

## The graphics card kept by its name (#56)

The menu stored the chosen card only as its position (`gpu_index`). On a laptop with an Intel and an NVIDIA card,
Windows changed the order of the list, the same position then named the Intel card, and the game ran out of its video
memory and stopped when a save loaded (`vk: device lost`, code 72). The menu now writes `gpu_name` with `gpu_index`;
when the two disagree, the name decides, in the device choice and in the preset's hardware probe alike. A position
alone still works as before.

- Each start logs `vk: card choice: ...`: `auto`, a position alone, a name alone, or both with `(both agree)` or
  `(they disagree: the name decides)`.
- A position alone that puts the game on an integrated card while a discrete one is there logs
  `vk: warning: gpu N "..." (integrated GPU) was chosen by gpu_index = N ...`, and a device loss adds the choice to the
  `fatal:` line.
- Test: `tests/gpu_choice_check.py` (C and C++).

## HDR on displays with many formats (#44, #57)

The swapchain read at most 64 surface formats, and some displays offer more: on one Wayland setup the HDR10 pair was
entry 67, so the game made an SDR swapchain and its HDR picture looked washed out. All formats are read now. The log
says `gfx: the surface offers N format and colour space pairs, all considered` once per change of the count. Test:
`tests/surface_formats_check.py`.

## Thread timing (#49)

Uniform snapshot drops are ordered by stream position, and the replay mirror's two shared counters are atomic. A
paired measurement on the bench found no frame-rate cost (-0.27%, within the bench's noise). A third report, on the
mirror's state, is benign by its lock order and suppressed in the ThreadSanitizer build instead, since making it
atomic cost about 2%.

## Uninstall on Linux (#55)

Uninstall removes the AppImage's install: the start script, the menu entry (only the one that starts this install)
and icon, the app versions, the Python runtime and `data/` except `data/logs`. It deletes after the launcher's window
has closed and logs `uninstall: removed N paths after the window closed`. The game folder and saves go only with
"Remove the Built Game", and never when that folder holds the home folder or the launcher's, or is a drive's root.
Paths the launcher shows on Linux use `/`.

## Tested

- Linux bench: builds and headless runs of #49 and of #44 with #57; ThreadSanitizer on the Kokiri window; the
  launcher test suite with the uninstall tests in a temporary home.
- Tests: `gpu_choice_check`, `surface_formats_check` (with sanitizers), `launcher_test`, `docs_i18n check`.
- Windows builds of each change by GitHub Actions.
- Not tried yet: the card choice on a player's laptop, HDR on a display with more than 64 formats, and Uninstall on a
