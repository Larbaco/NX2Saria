# NX2Saria 0.18.4 in detail

The option names, log lines and measurements behind the [0.18.4 release notes](../releases/v0.18.4.md).
How to install or update is in [the install guide](../install.md).

## Fixed

- **The Xbox, PlayStation, Steam Deck and keyboard button prompts** (#15, #19). Since NX2Saria's first release,
  picking any of them gave "prompt files missing" in the menu, and the game kept Nintendo's prompts.
  - The prompts are drawn on the player's PC while the game is built (`tools/pad_prompts.py`, the build's "prompts"
    step), from button pictures that the release has to carry in `app/<version>/prompt-art`. NX2navi's releases
    carried them under a licence given to its owner alone; NX2Saria's releases never did, and the step was skipped
    without a word.
  - The same 281 pictures are published by their author as the FREE Input Prompts Pack 1.4 by JulioCacko, under CC0
    1.0. They are now in the repository (`prompt-art/`), each byte for byte the pack's, with `SOURCE.md` (the pack,
    its page and an archived copy, the licence as the page states it, the SHA-256 of the download) and `SHA256SUMS`.
    `tools/check_content.py` refuses a picture in that folder that is not listed, or that differs from its listed
    SHA-256. CONTRIBUTING.md and AGENTS.md now allow art only with a clear free licence recorded this way.
  - `tools/make_launcher.py`, `make_kit.py` and `make_appimage.py` take that folder by default (`--prompt-art` takes
    another, `--no-prompt-art` none). The Windows release workflow fails when the app zip has no `prompt-art/`, and
    the AppImage workflow fails instead of warning.
  - An installed game that lacks the prompt folders gets them at this update ("a prompt folder is missing"), in about
    30 seconds; no reinstall is needed.
  - The menu's text for missing or damaged prompt files now says "update the game, or rebuild it in the launcher"
    ("Rebuild the Game" in the Windows launcher, "Update" in the Linux AppImage's window), in all four languages.
- THIRD_PARTY_NOTICES.md names the pack (JulioCacko, FREE Input Prompts Pack 1.4, CC0 1.0) in place of NX2navi's
  licence line.

## Its log

- The build: where the prompts were drawn from (`drawn from JulioCacko, FREE Input Prompts Pack 1.4 (CC0 1.0)`), or
  why there are none. The same line goes into `button-prompts.txt` in the game folder.
- The game: `button prompts: <that line> (button-prompts.txt)` at start, or a line saying the game folder has no
  record (a game built before 0.18.4, or made by hand).

## Tested

- The Windows release workflow on the branch: the app zip holds the 281 pictures, each with its SHA-256.
- On the Linux bench: a build drew the 7 prompt folders from the repository's art in 24 s, and its log and
  `button-prompts.txt` name the pack.
- `tests/launcher_test.py` (226 tests) and `tests/prompts_record_check.py` (C, with ASan and UBSan).
- Not yet: an update of an installed 0.18.1 on Windows.
