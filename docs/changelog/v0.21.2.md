# NX2Saria 0.21.2 in detail

The stable release after 0.21.1, made from the same code as
[0.21.2-rc.2](https://github.com/Larbaco/NX2Saria/releases/tag/v0.21.2-rc.2), which was tried on Windows. Players on
the Stable channel skipped the release candidates, so this release brings both:

- [0.21.2-rc.1](v0.21.2-rc.1.md): a lone `gpu_index` on an integrated card counts as Auto, and the shader
  preparation logs its card and the driver caches (#59); local times, system pressure and full counts in the log
  (#60).
- [0.21.2-rc.2](v0.21.2-rc.2.md): NVIDIA's shader cache in a folder beside the game on Windows (#63), and the mesh
  fallback by default on Intel (#64).

How to install or update is in [the install guide](../install.md), and how to check a downloaded file in
[Verify your download](../install.md#verify-your-download).

## Tried on Windows (laptop with an Intel and an NVIDIA RTX 3050, 6 GiB)

- The update to 0.21.2-rc.2 found NVIDIA's own cache empty and prepared the shaders once; the launcher's lines then
  showed `nvidia-cache 1.37 GB in 2 files` and NVIDIA's own folder still empty, so the Windows driver uses the
  folder the game names.
- Three starts afterwards: `library warm: NVIDIA's shader disk cache folder ... nvidia-cache holds 1.37` to
  `1.48 GB`, and the driver's cache had the prepared libraries (12, 11 and 12 of 12 sampled).
- `vk: card choice: gpu_index = 0, gpu_name = "NVIDIA GeForce RTX 3050 6GB Laptop GPU" (both agree)`; play with the
  game's own restart, no fatal error and no lost graphics device; the new `frametime:   system at` and
  `events in the whole run` lines.

## Known

- The next update on NVIDIA is the first that should find the shaders already in `nvidia-cache`; its launcher lines
  will show it.
- Not tried yet: the fog on an Intel Arc card (the player who reported it is asked in issue #13).
