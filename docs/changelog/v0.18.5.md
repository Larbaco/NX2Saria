# NX2Saria 0.18.5 in detail

The option names, log lines and measurements behind the [0.18.5 release notes](../releases/v0.18.5.md).
How to install or update is in [the install guide](../install.md).

0.18.5 is a pre-release to test two features on Windows with a real controller. Each has its own setting in
`nx2saria.ini`, so either can be turned off alone.

## New

- **The mouse in the game's own menus** (game 1.1.1, #18; [docs/menu-mouse.md](../menu-mouse.md)).
  - On the title, the save list, the pause menu, Options and the game's dialogs: moving the mouse moves the focus,
    left click is A, right click is B, and the wheel scrolls the lists.
  - After a menu closes, the mouse goes back to the camera (captured, confined and hidden). A gamepad press while a
    menu is open hides the pointer until the mouse moves again. The settings overlay (F1) and text entry take the
    mouse while they are open.
  - A click made while one menu closes and the next opens is not carried into the next one, and quick right clicks
    give one B: no B (the sword) reaches play.
  - Settings: `menu_cursor = 1|0` in `[input]` (live; Controls tab, "Mouse in the game's menus").
    `NX2SARIA_MENU_MOUSE_PATCH=0` takes the game patch out; `NX2SARIA_MENU_CURSOR_LOG=1` logs each step.
- **Gyro calibration, dead zone and per-axis options** (#14; [docs/gyro.md](../gyro.md)).
  - After 0.5 s still, the gyro's reading at rest is learned as its bias and subtracted, learned again at every rest,
    and kept per controller (the last four).
  - Settings, all live, in a new Gyro group on the Controls tab: `gyro_calibration = 1|0` (0 uses the readings as the
    controller sends them), `gyro_deadzone = off|low|standard|high` (default low, 0.002 revolutions a second; it
    replaces the zero-drift mode the game asks for), `gyro_turn_sens` and `gyro_tilt_sens` (10 to 400 %),
    `gyro_turn_invert` and `gyro_tilt_invert`. With the defaults, the change from before is that the learned bias is
    subtracted and the slowest turns are zeroed.

## Its log (`logs/nx2saria.log`)

- Menu mouse: `input: the mouse captured for the camera (confined and hidden)`, `menu_mouse: <screen>: the gamepad was
  used last: the pointer hidden`, `... the settings overlay or a text entry is open`, and counts per session.
- Gyro: `motion: settings: ...` at start and at each change, `hid: the game sets the gyroscope zero-drift mode ...`,
  `input: motion sensors on "<controller>"`, `motion: bias learned ... after N ms still`,
  `motion: sensors of "...": bias ... restored`, and every 300 s `motion: last 300 s: ...` with the drift before and
  after.

## Tested

- Menu mouse: `tests/menu_mouse_check` (including a click between menus, four quick right clicks giving one B, and the
  queue dropped when a menu closes); headless runs on the Linux bench with scripted mouse input: the focus followed the
  pointer on the save list, A and B and the wheel acted, and the camera received the mouse in play. An independent
  review checked the patch site, the reads of game memory, the capture and both off switches; its four findings were
  fixed before this release.
- Gyro: `tests/motion_fusion_check.py` (16 synthetic cases: bias at rest, dead zone levels, known rotations, tremor,
  re-learning, per-controller cache, sensitivities).
- The Windows builds of both were made by the release workflow. Not yet: either one played on Windows with a physical
  controller. That is what this pre-release is for.
