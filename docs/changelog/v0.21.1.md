# NX2Saria 0.21.1 in detail

The stable release after 0.21.0, made from the same code as
[0.21.1-rc.1](https://github.com/Larbaco/NX2Saria/releases/tag/v0.21.1-rc.1), which was tried on Windows and Linux.
The changes, their log lines and tests are in [the 0.21.1-rc.1 details](v0.21.1-rc.1.md): the graphics card kept by
its name (#56), HDR on displays with many formats (#44, #57), thread timing (#49) and Uninstall on Linux (#55).

How to install or update is in [the install guide](../install.md), and how to check a downloaded file in
[Verify your download](../install.md#verify-your-download).

## Tried

- Windows (laptop with an Intel and an NVIDIA RTX 3050, 6 GiB): the card chosen again in the menu, then
  `vk: card choice: gpu_index = 0, gpu_name = "NVIDIA GeForce RTX 3050 6GB Laptop GPU" (both agree)`; a save loaded and
  about 30 minutes of play over two sessions with FSR 3 frame generation, no fatal error and no lost graphics device;
  `gfx: the surface offers 5 format and colour space pairs` once per session.
- Linux (RX 6700): about 30 minutes of play, `vk: card choice: auto`, the surface line once, and
  `the game ended with code 0`.

## Known

- Each update prepares the shaders for an NVIDIA card again, which took 15 to 30 minutes on the RTX 3050 laptop. On
  Linux the same step is skipped when the driver's cache still holds them. This is being looked at.
- On the Linux test PC (RX 6700, RADV), the graphics card stopped twice in one day during play, as it has now and
  then since early November; the cause is being looked at.
- Not tried yet: HDR on a display with more than 64 formats, and Uninstall on a player's Linux PC.
