# NX2Saria 0.19.0 in detail

The stable release after 0.18.6, made from the same code as
[0.19.0-rc.2](https://github.com/Larbaco/NX2Saria/releases/tag/v0.19.0-rc.2), which was tried on Windows. Players on
the Stable channel skipped the pre-releases in between, so this release brings all of them:

- [0.18.7](v0.18.7.md): field of view on game 1.1.1 (its first version; it acted from 0.19.0-rc.1 on), the high frame
  rate fixes (Epona's fence jumps, Gohma's turn, the frozen Zoras, the battle music), the voice language after a
  restart, speech balloons on ultrawide screens, and the memory-failure messages at start.
- [0.19.0-rc.1](v0.19.0-rc.1.md): the pause menu's tabs by mouse, the field of view's camera filter fixed, personal
  folders and names out of logs and reports, a full model heap no longer crashing, and releases made by GitHub Actions
  with a provenance attestation for every file.
- [0.19.0-rc.2](v0.19.0-rc.2.md): what each button does, on the Controls tab.

How to install or update is in [the install guide](../install.md), and how to check a downloaded file in
[Verify your download](../install.md#verify-your-download).

## Tried on Windows (0.19.0-rc.2, RTX 3050 Laptop)

- Field of view: `fov: gameplay lens adjusted, 50.00 -> 60.00 deg` at 120 % and `50.00 -> 70.00 deg` at 140 %; the lens
  left alone for events, the event and 3D UI cameras, first-person aiming and the pause menu.
- The pause menu's tabs: System and Collection clicked and reached by mouse.
- No account or computer name in the game's logs or the launcher's log from 0.19.0-rc.2 on.
- `heap retry: on` with no refusal (a full model heap has not been seen in a real log yet); the button labels on.

## Known

- An update or the first start can rebuild the shaders in the graphics driver's cache for a long time when the
  driver dropped part of that cache (seen once on an NVIDIA laptop: about two hours, most of it on three very large
  compute shaders the game never uses). 0.19.1 leaves those out of the preparation and stops a preparation stuck on
  one shader after a few minutes, letting the game finish it in the background.
