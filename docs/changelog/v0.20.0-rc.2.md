# NX2Saria 0.20.0-rc.2 in detail

The log lines and tests behind the [0.20.0-rc.2 release notes](../releases/v0.20.0-rc.2.md). How to install or update
is in [the install guide](../install.md). It is the second release candidate of 0.20.0, for launchers on the Preview
channel, and has everything of [0.20.0-rc.1](v0.20.0-rc.1.md) (quality presets, the scene below the picture's size,
dynamic resolution on 1.1.1, 16:10 and 3:2 pictures) plus the changes below.

## The HUD is back (#43)

0.20.0-rc.1 showed no HUD at any picture shape, 16:9 included. The 16:10 change (#40) added a load of the UI's
vertical squeeze to the `wide_hud` patch site (main+0x774368) through a register that by then held the canvas or its
screen, not the patch page, so the HUD's height was multiplied by an unrelated value. The load now reads the page.
`tests/wide_hud_projection_check.py` checks the base register of every page load in that site and fails on the old
code.

## Linux launcher groundwork (#41)

The first part of the launcher on Linux, not yet in the AppImage, which keeps its current window:
- a controller through SDL3 (the kit's library, else the system's), found again after it is unplugged;
- `systemd-inhibit` keeps the PC awake during a build and ends with the launcher;
- a check of the compiler and libraries the build needs, naming the packages for each distribution.

Log, in `launcher.log`: `gamepad: SDL3 from the kit|system|none (...)`, `keep awake: systemd-inhibit
held|released|unavailable` and the tools check. On Windows the controller goes through the same XInput code as
before, behind a new shared front.

## Tested

  in 0.19.1 and in this release at 21:9 (2560x1080), 16:9 (1920x1080) and 16:10 (1280x800).
- Windows builds of both changes by GitHub Actions.
- Not tried yet: the presets and 16:10 on Windows, and the launcher's controller on Linux.
