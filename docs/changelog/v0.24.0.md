# NX2Saria 0.24.0 in detail

The stable release after 0.23.0, made from the same code as
[0.24.0-rc.1](https://github.com/Larbaco/NX2Saria/releases/tag/v0.24.0-rc.1), which was played on Windows. Its
changes, with their log lines and tests, are in [0.24.0-rc.1 in detail](v0.24.0-rc.1.md):

- the Cheats tab of the game's menu, and the log's count of each cheat's writes (#85);
- session reports and comments, with the launcher's question after an update (#37);
- comments moved from the code to `docs/code/` for four more parts of the runtime (#82, #83, #84, #86).

How to install or update is in [the install guide](../install.md), and how to check a downloaded file in
[Verify your download](../install.md#verify-your-download). What a session report holds is in
[telemetry.md](../telemetry.md).

## Played on Windows (laptop with an NVIDIA RTX 3050, 6 GiB)

- The update from 0.23.0-rc.1: `background update: installing 0.24.0-rc.1`, then the game's rebuild, `23 compiled, 584
  unchanged`, `compile: 27 s`, the prepared shaders kept, and `job update: ok` 67 s after the launcher's start.
- The question, at the launcher's next start: `telemetry: the question's countdown stopped at the first input`,
  `setting: telemetry '' -> on`, `telemetry: asked after the update to 0.24.0-rc.1: send`. Its title and countdown line
  showed whole.
- A comment and a session report: `telemetry: comment sent (HTTP 201, 26735 bytes)` and `telemetry: session report
  sent (HTTP 201, 2002 bytes)`; the server holds both, and the report's numbers are those of the game's own log
  (158 s, 3645 frames, 27.4 fps).
- Two sessions ended with `the game ended with code 0`; no fatal error and no lost graphics device.
- `cheats: no enabled mod holds cheats/<id>.txt; the menu has no Cheats tab` in both, as expected without a cheats mod.
- Against a session of 0.23.0-rc.1 of the same day with the same settings (DLAA at 2560x1080 with FSR 3 frame
  generation, over this card's video memory in both versions): 36.2 and 31.6 fps in the first minute against 39.0, and
  24 to 27 fps afterwards against 29.4; the stretches played were not the same.

## Session reports of the candidate

Five reports of 0.24.0-rc.1 reached the server before this release, from four computers:

- Windows with three graphics cards (one NVIDIA, two AMD): four sessions, two of them longer than 40 minutes, all
  ended normally.
- Linux with an older AMD card: one session, ended after 44 s with a lost graphics device. Its cause is not known; the
  drawing code is the same as in 0.23.0.

## Known

- The question does not come at the launcher start that finishes an update's rebuild of the game but at the start
  after it, and the session played in between is not reported.
- The Cheats tab was tried with the menu's test hook in four languages, not with a controller or a mouse.
- Not confirmed: the question answered with a controller, and an update on Linux from a released version.
- DLAA at 2560x1080 with frame generation does not fit 6 GiB of video memory (`made over the VRAM budget (5406 of 5249
  MiB in use ...)`), and the frame rate falls. A DLSS mode fits.
