# NX2Saria 0.27.0-rc.3 in detail

The log lines and tests behind the [0.27.0-rc.3 release notes](../releases/v0.27.0-rc.3.md). How to install or update
is in [the install guide](../install.md). It is the third release candidate of 0.27.0, for launchers on the Preview
channel, and has everything of [0.27.0-rc.2](v0.27.0-rc.2.md) plus the change below.

## A settings tab in the game's pause menu (#130)

Experimental, off by default, game 1.1.1 only. What it is and how it is made: [pause-settings-tab.md](../pause-settings-tab.md).

- `pause_settings_tab = 1` in `nx2saria.ini` shows a fifth name after the pause menu's *Menu* tab: "NX2Saria", or the
  menu language's "Settings" with `pause_settings_tab_name = settings`. R on the *Menu* tab opens it, and so does a
  click on its name; L, B or Plus closes it.
- The *Menu* tab's page is hidden and the settings menu's own picture rows are drawn in its place: the frame limit,
  VSync, the upscaler, frame generation, sharpening and anisotropic filtering, with the same draft and the same
  "Apply your changes?" box. No file of the game is replaced and no new patch of its code is made: the tab's name and
  page are drawn over the game's menu.
- With the option off nothing changes: on the test computer the pause menu's picture was the same as before to the
  pixel, and the settings menu's five pages were the same.
- If the tab cannot be drawn it closes and the *Menu* tab's page comes back; a test forces that. It does not show in
  the Minus menu.
- Log: at the start whether the tab is on and why not; when the tab opens and closes; and each Apply made from it,
  `pause_tab: Apply from the tab: 1 change(s): ...`.
- Seen on the test computer with scripted input: sharpening changed from 80 to 85 through the tab, `sharpness = 85`
  written to `nx2saria.ini` and shown again when the tab was reopened; Portuguese and Simplified Chinese, 16:9 and
  21:9.
- Test: `tests/pause_tab_check.py`. Notes: [code/ui.md](../code/ui.md).

## Known

- The tab's name is drawn smaller than the game's own tab names, and "Settings" in some languages is hard to read.
  The game's R icon stays between the *Menu* tab and the new one.
- Not tried: a real controller, the mouse click on the tab's name, a real 21:9 window (the test window is small and
  the panel looks narrow there), Windows.
- The other groups of the settings menu (sound, controls, game) are not in the tab yet.
- Not played yet with this build: DLSS and DLAA on Windows with the NGX lock, and the launcher's window on Windows.
