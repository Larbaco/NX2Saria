# NX2Saria 0.24.0-rc.1 in detail

The log lines and tests behind the [0.24.0-rc.1 release notes](../releases/v0.24.0-rc.1.md). How to install or update
is in [the install guide](../install.md). It is the first release candidate of 0.24.0, for launchers on the Preview
channel, and has everything of [0.23.0](v0.23.0.md) plus the changes below.

## The Cheats tab (#85)

The port of the menu to this game had left the Cheats tab out, so a cheat could only be switched on by writing its key
in `nx2saria.ini`. The tab is the menu's sixth and shows only when an enabled mod holds cheats for the game's build.
A change stays in the draft until Apply, as on the other tabs (`<name>: Off -> On` in the Apply box), and the cheat
acts from the first frame after it. A code cheat not built into the game is shown greyed, with the line that Play from
the launcher builds it in.

- Start: `cheats: <id>.txt in 1 mod: 2 cheats, 0 on; ... the menu's Cheats tab lists them`, or `no enabled mod holds
  cheats/<id>.txt; the menu has no Cheats tab`.
- Change: `menu: draft + CHEAT_<key>: ... (staged: waits for Apply)`, then `cheats: <mod>/<name> on` or `off`.
- While a cheat is on: `cheats: <mod>/<name>: N writes in N frames, N unchanged, N refused so far`, at the first write
  or refusal and at most once a minute, and the session's totals at the end. A refused write is one to memory the game
  has not mapped.
- Nothing about cheats or mod names goes into the session report.
- Tests: `tests/cheats_tab_check.py`. Tried with the menu's test hook in English, Portuguese, Russian and Simplified
  Chinese; not with a controller or a mouse.

## Session reports and comments (#37)

Described for players in [telemetry.md](../telemetry.md): what a report holds, when the launcher asks, and what is not
sent or kept. The server is the project's own Cloudflare Worker, whose source is in `telemetry/`.

- The question comes at the first start of each version while reports are off, and never while they are on. Send is
  the selected button; closing the question or 30 s without input turn reports on, and the first line of the question
  says so and counts down. Any input stops the countdown. Only Don't Send keeps them off.
- The first report is the one of the next session played; then one each time the game ends. Nothing is sent in play.
- A report has no installation id and the server stores no country and no IP address, so reports cannot be tied to an
  installation and there is nothing to delete on request; they are deleted after 180 days.
- New fields: the names of the port's patch sets that are on, and how many mods are enabled and how many of them bring
  code, without their names.
- Launcher log: `telemetry: asked after the update to X: send|don't send|closed (on)|timeout (on)`, and
  `telemetry: session report sent (HTTP 201, N bytes)` for each report.
- `NX2SARIA_TELEMETRY_URL=none` turns all of it off.
- Tests: `tests/telemetry_launcher_test.py`, `tests/session_summary_check.py`, `tests/telemetry_patch_sets_check.py`,
  and the Worker's own in `telemetry/test/`.
