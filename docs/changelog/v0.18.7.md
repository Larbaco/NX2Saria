# NX2Saria 0.18.7 in detail

The option names, log lines and measurements behind the [0.18.7 release notes](../releases/v0.18.7.md).
How to install or update is in [the install guide](../install.md).

0.18.7 is a pre-release to test a batch of game fixes (#22) and the memory-failure messages (#21). Each game fix has
its own setting, on by default, so any one can be turned off alone.

## New and fixed (game 1.1.1, #22)

Addresses found in other ports of the same game (GPL-3.0: only the idea and the address, checked against our own
binary's bytes; none of their code is used).

- **Field of view on 1.1.1** (`fov`, 70 to 140 %, Display tab; it was shown only on 1.4.3). It widens the gameplay
  camera and leaves cutscenes and game events, the message log, the pause and map screens and first-person aiming
  (slingshot, bow, hookshot) as the game draws them. Log: `fov: on, N%` with what it skips, then
  `fov: gameplay lens adjusted ...`.
- **High frame rate fixes**, which act only above 60 fps:
  - `horse_jump_fix`: Epona's jump over fences uses the short frame, so she no longer runs through them.
  - `gohma_turn_fix`: Gohma's turn limit is scaled to the frame, so she reaches her point on the ceiling.
  - `frozen_zora_fix`: the frozen Zoras' one-frame animation loop stays still instead of shaking.
  - `battle_music_fix`: the flags that end the battle music are kept across the sound updates the 60 Hz sound gate
    skips, so the music stops after the fight.
  Each logs when it acts (`horse jump blend`, `Gohma steering clamp`, `single-frame loop`, `battle music change`),
  a few times per session.
- `voice_language_fix`: the voice language picked in the menu is applied again after the save loads, so it sticks
  after a restart (one `voice language: refresh` at start).
- `balloon_anchor_fix`: speech balloons are anchored to the speaker under the HUD's ultrawide squeeze
  (`balloon: on, UI horizontal scale ...`, then `balloon: anchor x ... -> ...`).
- Not done: text choices cut at 16:10 (no safe place to fix without reproducing it) and balloons at 4:3 (not
  reproduced).

## Memory failures at start (#21)

- When Windows refuses memory the game needs, the fatal line and the launcher's message now give the Windows error
  (code and name), the range and size, and the system's commit. For "the commit limit was reached" (1455) and the
  like, the message says what to do: close memory-heavy programs, turn on or enlarge the page file (32 GB fixed on a
  16 GB PC), restart Windows. Linux reports its own error number.
- Before Play (also from Steam), the launcher logs the commit left, the RAM and the page file mode. Only when the page
  file is fixed-size or off and the commit left is below the game's need, it asks before starting, with "Play anyway"
  as the default; "Warn About Low Commit" in the launcher's settings, or `mem_need_mb = 0`, turns the question off.

## Tested

- #22: `fov_check`, `frame_step_check`, `animation_loop_check`, `battle_music_check`, `voice_language_check`,
  `wide_balloon_check`, `cfg_parse_check`, `cfg_rows_check`; Linux bench build and two headless runs to Hyrule Field
  showing the start lines. An independent review checked all 13 patch sites against the binary's bytes, the patch
  page slots, the off switches and the FOV's exclusions (read from the game). Not seen acting yet: the fights,
  fences, Gohma, frozen Zoras and conversations; the FOV may jump when the pause opens or during some game events.
- #21: message-selection and launcher tests; an independent review of the error capture and the fatal path.
- The Windows builds of both were made by the release workflow; neither has been played on Windows yet.
