# NX2Saria 0.21.0 in detail

The stable release after 0.20.0, made from the same code as
[0.21.0-rc.3](https://github.com/Larbaco/NX2Saria/releases/tag/v0.21.0-rc.3), which was tried on Windows and Linux.
Players on the Stable channel skipped the release candidates, so this release brings all three:

- [0.21.0-rc.1](v0.21.0-rc.1.md): the full launcher installed by the Linux AppImage, with background updates and the
  Applications menu entry (#42); timing fixes between the game's threads found with ThreadSanitizer (#47); Apply no
  longer lists an option a preset gave back at the same value (#48); the frame-time summary says when the game is
  bound by one serial step (#46).
- [0.21.0-rc.2](v0.21.0-rc.2.md): the udmabuf offer on Linux (#45), the Linux install and update fixes (#50), and the
  launcher's log, dump search on other drives, desktop file choosers and lighter animations (#51).
- [0.21.0-rc.3](v0.21.0-rc.3.md): Play on Linux (#54) and Add to Steam on Linux and the Steam Deck (#52).

How to install or update is in [the install guide](../install.md), and how to check a downloaded file in
[Verify your download](../install.md#verify-your-download).

## Tried

- Linux (RX 6700): the AppImage install, the update from rc.1 to rc.2 and from rc.2 to rc.3 from the Preview
  channel, Play from the launcher with three restarts from the game's menu, and `the game ended with code 0`.
- Windows (RTX 3050 Laptop, 6 GiB): a save loaded and about 7 minutes of play with FSR 3 frame generation, no fatal
  error and no lost graphics device; video memory peaked at 3180 of 5249 MiB.

## Known

- On a PC with an integrated and a discrete graphics card, the card chosen in the menu is kept by its position in
  the list. When Windows changes the list's order, the game can start on the integrated card, run out of video
  memory and stop when a save loads (`vk: device lost`, code 72). Choose the card again in the menu, or Auto. 0.21.1
  keeps the choice by the card's name too (#56).
- The first start on a graphics card that has not run this version yet prepares its shaders again: about a minute and
  a half on the RTX 3050 Laptop, then seconds.
- Not tried yet: Add to Steam on a Steam Deck.
