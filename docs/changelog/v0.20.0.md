# NX2Saria 0.20.0 in detail

The stable release after 0.19.1, made from the same code as
[0.20.0-rc.2](https://github.com/Larbaco/NX2Saria/releases/tag/v0.20.0-rc.2), which was tried on Windows. Players on
the Stable channel skipped the release candidates, so this release brings both:

- [0.20.0-rc.1](v0.20.0-rc.1.md): quality presets (#33), the scene below the picture's size, dynamic resolution on
  game 1.1.1 (#34), and 16:10 and 3:2 pictures (#40). The option names, log lines and tests are there and in
  [docs/presets.md](../presets.md).
- [0.20.0-rc.2](v0.20.0-rc.2.md): the HUD that 0.20.0-rc.1 lost at every picture shape is back (#43), and the first
  part of the launcher on Linux (#41), not yet in the AppImage.

How to install or update is in [the install guide](../install.md), and how to check a downloaded file in
[Verify your download](../install.md#verify-your-download).

## Tried on Windows (0.20.0-rc.2, RTX 3050 Laptop, 6 GiB)

- The HUD at 16:9: `wide hud: center ... no pane moves`, hearts, magic, items and the minimap shown.
- The presets: `preset: recommended medium: 6 GiB`, the one-time notice, each tier chosen in the menu, the *(custom)*
  mark after a hand-set option, and `preset: in use low (settings file)` at the next start.
- About two hours of play with no fatal error, no lost graphics device and no crash.

## Known

- Apply can list an option that a preset choice handed back at the value it already had as a change
  (`GAME_RES: '1080' -> '1080'`). Nothing changes and only a real change asks for a restart. 0.20.1 will leave such
  options out of the list (#48).
- A player saw some spider webs disappear in the Deku Tree. The bench draws them at every preset, in this release and
  in 0.19.1, and the cause is being looked at.
- Not tried on Windows yet: dynamic resolution and a 16:10 picture. Both were tried on the Linux bench.
