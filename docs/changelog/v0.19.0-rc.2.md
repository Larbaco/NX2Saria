# NX2Saria 0.19.0-rc.2 in detail

The option names, log lines and tests behind the [0.19.0-rc.2 release notes](../releases/v0.19.0-rc.2.md).
How to install or update is in [the install guide](../install.md).

0.19.0-rc.2 is the second release candidate of 0.19.0, for launchers on the Preview channel. It is 0.19.0-rc.1
([details](v0.19.0-rc.1.md)) plus the button actions on the Controls tab; 0.19.0 will be made from this code once it
has been tried on Windows.

## What each button does, on the Controls tab (#30)

- Each row of the button bindings shows, under the Switch button's name, a short label of what that button does in
  the game, in a smaller, dimmer line: A "Actions / dash", B "Put away / back", X "Jump", Y "Sword attack", L and R
  "Items / prev. pg" and "Items / next pg", ZL "Target", ZR "Use item", + "Pause menu", − "Map", the d-pad "Ocarina",
  "Accessory", "Talk to Navi" and "Change boots", the right stick's press "Reset camera", the sticks "Move" and
  "Camera". The left stick's press has no action of its own and no label.
- The labels follow the game's button of the row, not the key or button bound to it: swapping bindings does not move
  them. They are in the menu's four languages (English, Português do Brasil, Русский, 简体中文) and fit the column
  at 1280x720 without being cut.
- The descriptions of B and X say again that the game's Options can swap jump and put away; the labels show the
  default (B puts away, X jumps), since the port does not read that game option.
- Log, once at the menu's first frame: `menu: bind action labels on (24 rows; default B/X; Swap Jump Controls not
  read)`.
- The test hook's `FOCUS=` takes a bind cell too (`BIND_L#0`), for captures of a row below the first screen.

## Tested

- `bind_labels_test` (every row has a label or none in all four languages, and each fits the column width measured
  on captures at 1280x720), the content check and the translations check.
- Bench (Linux, headless): captures of the Controls tab in Brazilian Portuguese at 1280x720, English at 1920x1080 and
  Russian at 1280x720, every label whole; the settings file unchanged.
- The Windows build of the change by the release workflow.
