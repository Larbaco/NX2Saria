# Установка и обновление NX2Saria

В каждом выпуске на [странице Releases](https://github.com/Larbaco/NX2Saria/releases) есть установщик для Windows и
AppImage для Linux. Ни один из них не содержит данных игры: оба собирают игру на вашем ПК из вашего собственного дампа
`.nup` издания для Nintendo Switch 2 с обновлением 1.1.1. В [README](../../README.ru.md#требования) указано, что нужно
вашему ПК.

## Windows

1. Скачайте **`NX2Saria-Setup-<version>.exe`** из выпуска.
2. Положите его рядом с дампом `.nup` и запустите.
3. При первом запуске Windows SmartScreen выдаёт предупреждение, потому что установщик не подписан: выберите
   *Подробнее* (*More info*), затем *Выполнить в любом случае* (*Run anyway*).

Установщик устанавливает лаунчер, который один раз собирает игру, а затем запускает её.

## Linux

1. Скачайте **`NX2Saria-Linux-<version>-x86_64.AppImage`** из выпуска.
2. Сделайте его исполняемым (`chmod +x NX2Saria-Linux-*.AppImage`) и запустите.

При запуске на рабочем столе он открывает окно для установки, обновления и игры.

## Обновление

- **Лаунчер сам предлагает каждый новый выпуск**, начиная с NX2Saria 0.12.1.
- **Лаунчер, установленный из исходного проекта NX2navi,** сохраняет источник обновлений, с которым был установлен.
  Один раз задайте `"feed_repo": "Larbaco/NX2Saria"` в его `data/launcher.json`, и с этого момента он будет предлагать
  выпуски NX2Saria.
- **Папка игры, сохранения, профили, моды и `nx2saria.ini` остаются на месте**, когда вы обновляетесь.
- **Предварительные выпуски** получают только лаунчеры, у которых настройка *Update Channel* равна *Preview*. На
  *Stable*, значении по умолчанию, лаунчер ждёт, пока выпуск не будет отмечен как стабильный.

## Что-то не так?

В разделе [Известные проблемы](known-issues.md) перечислены известные нам проблемы и способы их обойти. Во всех
остальных случаях создайте задачу (issue) на https://github.com/Larbaco/NX2Saria/issues и приложите
`logs\nx2saria.log` (`logs/nx2saria.log` в Linux) из папки игры.

[Руководство по лаунчеру](../launcher.md) (на английском) и [руководство по установщику](../installer.md) (на
английском) подробно описывают, как они работают.
