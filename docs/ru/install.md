# Установка и обновление NX2Saria

В каждом выпуске на [странице Releases](https://github.com/Larbaco/NX2Saria/releases) есть установщик для Windows и
AppImage для Linux. Ни один из них не содержит данных игры: оба собирают игру на вашем ПК из вашего собственного дампа
`.nup` издания для Nintendo Switch 2 с обновлением 1.1.1. В [README](../../README.ru.md#требования) указано, что нужно
вашему ПК.

## Windows

1. Скачайте **`NX2Saria-Setup-<version>.exe`** из выпуска.
2. Положите его рядом с дампом `.nup` и запустите.
3. При первом запуске Windows SmartScreen выдаёт предупреждение, потому что установщик не подписан: выберите
   *Подробнее* (*More info*), затем *Выполнить в любом случае* (*Run anyway*).

Установщик устанавливает лаунчер, который один раз собирает игру, а затем запускает её.

## Linux

1. Скачайте **`NX2Saria-Linux-<version>-x86_64.AppImage`** из выпуска.
2. Сделайте его исполняемым и запустите. В терминале: `chmod +x NX2Saria-Linux-*.AppImage`. В файловом менеджере:
   щёлкните по нему правой кнопкой, затем **Свойства > Права > Разрешить выполнение файла как программы**. До
   этого двойной щелчок может открыть файл в другой программе (менеджере архивов или менеджере AppImage), а не
   запустить его.
3. Для сборки нужны компилятор и несколько библиотек из вашего дистрибутива. Если чего-то не хватает, AppImage
   называет, чего именно, и команду для установки. В Ubuntu 24.04, Linux Mint 22 и других дистрибутивах на основе
   Ubuntu:

   ```sh
   sudo apt install clang lld libopus-dev libvpx-dev libdav1d-dev libzstd-dev libvulkan-dev
   ```

   SDL3, которого нет в пакетах Ubuntu 24.04, поставляется вместе с AppImage.

При первом запуске AppImage устанавливает лаунчер и среду Python в `~/.local/share/nx2saria`, а затем открывает
установленный лаунчер. Запись в меню приложений указывает на установленную копию, поэтому после этого AppImage можно
переместить или удалить. Сохраните его, если понадобится восстановить или переустановить лаунчер. Если вы пользовались
прежним окном AppImage, новый лаунчер подхватит дамп и папку игры из `~/.config/nx2saria/appimage.json` (а также из
старого пути `nx2navi`), не перемещая эти папки.

## Обновление

- **Лаунчер сам предлагает каждый новый выпуск**, начиная с NX2Saria 0.12.1.
- **Лаунчер, установленный из исходного проекта NX2navi,** сохраняет источник обновлений, с которым был установлен.
  Один раз задайте `"feed_repo": "Larbaco/NX2Saria"` в его `data/launcher.json`, и с этого момента он будет предлагать
  выпуски NX2Saria.
- **Папка игры, сохранения, профили, моды и `nx2saria.ini` остаются на месте**, когда вы обновляетесь.
- **Предварительные выпуски** получают только лаунчеры, у которых настройка *Update Channel* равна *Preview*. На
  *Stable*, значении по умолчанию, лаунчер ждёт, пока выпуск не будет отмечен как стабильный.

## Проверка загрузки

Начиная с NX2Saria 0.19.0-rc.1, все файлы выпуска собирает и загружает GitHub Actions, и ни один файл не проходит
через чей-либо ПК. У каждого файла есть **аттестация происхождения** (provenance attestation): подписанная GitHub
запись о том, какой репозиторий, какой workflow и какой коммит его собрали. Если бы файл изменили после сборки,
аттестация бы ему не соответствовала.

**Проверьте аттестацию** с помощью [GitHub CLI](https://cli.github.com/) (`gh`, с входом в любую учётную запись
GitHub) в папке, куда вы скачали файл:

```sh
gh attestation verify NX2Saria-Setup-0.19.0.exe --repo Larbaco/NX2Saria \
  --signer-workflow Larbaco/NX2Saria/.github/workflows/release.yml --source-ref refs/tags/v0.19.0 \
  --deny-self-hosted-runners
```

(В Windows, в PowerShell, напишите всё в одну строку без `\`.)

Подставьте вместо `NX2Saria-Setup-0.19.0.exe` имя скачанного файла, а в `refs/tags/v0.19.0` — его версию: так же
проверяются AppImage, zip-архивы app и runtime для Windows и Linux, все три манифеста обновления и `SHA256SUMS.txt`. Для
правильного файла команда выводит `✓ Verification succeeded!` и workflow, который его собрал. Любой другой ответ
означает, что это не тот файл, который GitHub Actions собрал для этой версии: не запускайте его и сообщите нам в issue.

**Проверьте контрольные суммы.** `SHA256SUMS.txt` в выпуске перечисляет SHA-256 всех остальных файлов. Он показывает,
что загрузка дошла целиком; вместе с аттестацией самого `SHA256SUMS.txt` он показывает и то, откуда взят каждый файл.

- Linux: `sha256sum -c --ignore-missing SHA256SUMS.txt` выводит `OK` для каждого скачанного файла.
- Windows (PowerShell): `Get-FileHash NX2Saria-Setup-0.19.0.exe` выводит SHA-256; он должен совпадать с указанным в
  строке этого файла в `SHA256SUMS.txt` (регистр букв не важен).

При каждом обновлении лаунчер сам выполняет вторую проверку: Windows скачивает `NX2Saria-update.json`, а Linux —
`NX2Saria-update-linux.json`. Каждая платформа читает только свой манифест и устанавливает app или runtime, только
если размер и SHA-256 совпадают с указанными в манифесте. Выпуски старше 0.19.0-rc.1 загружались вручную, и
аттестации у них нет.

## Что-то не так?

В разделе [Известные проблемы](known-issues.md) перечислены известные нам проблемы и способы их обойти. Во всех
остальных случаях создайте задачу (issue) на https://github.com/Larbaco/NX2Saria/issues и приложите
`logs\nx2saria.log` (`logs/nx2saria.log` в Linux) из папки игры.

[Руководство по лаунчеру](../launcher.md) (на английском) и [руководство по установщику](../installer.md) (на
английском) подробно описывают, как они работают.
